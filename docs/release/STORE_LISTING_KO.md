## 6. 게시 전 승인

- [ ] 출시 후보 기능과 설명이 일치한다.
- [ ] 학교·조직·상표·로고 사용 승인이 있다.
- [ ] 운영 주체, 개발자명, 저작권 표기가 법적 문서와 일치한다.
