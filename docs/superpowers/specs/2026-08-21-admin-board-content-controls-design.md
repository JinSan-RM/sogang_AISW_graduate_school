# Admin Board Content Controls Design

## Goal

관리자 `게시글 관리`를 그룹과 실제 게시판별로 탐색할 수 있게 하고, 선택한 게시판의 성격에 맞는 운영 기능을 한곳에서 제공한다. QA 180의 동아리 안내 대표 이미지 변경은 `참여활동 > 동아리 홍보`에서 직접 수행한다.

## Approved information architecture

- `게시판` 메뉴는 게시판 이름, 권한, 노출 상태와 정렬을 관리하는 설정 화면으로 유지한다.
- `게시글` 메뉴는 실제 콘텐츠를 관리하는 화면으로 유지한다.
- `게시글` 화면의 첫 번째 단계는 `전체 / 공지사항 / 참여활동 / 커뮤니티·자료 / 원우회` 그룹 탭이다.
- 그룹을 선택하면 해당 그룹에서 실제 게시글을 가지는 게시판만 두 번째 단계의 게시판 탭으로 표시한다.
- `전체`는 현재처럼 모든 게시글을 보여주고, 나머지 그룹은 게시판 하나를 명시적으로 선택해 그 게시판의 게시글만 보여준다.
- 캘린더, 외부 링크, 원우회 소개 메타데이터, FAQ, 가이드처럼 표준 게시글 목록이 아닌 콘텐츠는 게시글 탭에서 제외하고 기존 전용 관리자 화면을 유지한다.

## Board-specific controls

- 모든 표준 게시판: 사용자 화면 열기, 글 수정, 고정/고정 해제, 삭제, 검색.
- 관리자 작성 게시판: 선택한 게시판에 맞는 명칭의 새 글 등록 버튼.
- 공지 게시판: 기존 `공지사항` 전용 관리 화면으로 이동하는 버튼과 공지 전용 설명.
- `club-promo`: 현재 대표 이미지 미리보기와 `대표 이미지 변경`, 가입 링크/본문 수정을 위한 일반 수정 버튼.
- `networking-programs`: 현재 대표 이미지 미리보기와 `대표 이미지 변경`, 참가 링크/본문 수정을 위한 일반 수정 버튼.
- `suggestion`: 기존 건의사항 답변 관리 화면으로 이동하는 버튼.
- `mutual_aid`: 기존 상조회 처리 관리 화면으로 이동하는 버튼.
- 앨범: 이미지 중심 게시판이라는 안내와 기존 작성 화면 연결.
- 활동 인증: 활동일, 참여자, 사진 등 해당 작성 화면을 재사용하며 관리자 목록의 공통 운영 기능을 유지한다.
- 자료 게시판: 파일 첨부와 게시판 이동 규칙을 유지하며 공통 운영 기능을 제공한다.
- 원우회 소개, 기장단, 역대 원우회, FAQ는 기존 전용 관리자 섹션에서 계속 관리한다.

## Representative image replacement

동아리와 네트워킹 안내의 대표 이미지는 첨부 이미지 중 정렬 순서가 가장 빠른 이미지다. 관리자 카드에서 이미지 한 장을 선택하면 게시글 상세를 다시 읽고 다음 규칙으로 첨부 순서를 만든다.

1. 기존 첫 번째 이미지가 있으면 같은 위치를 새 이미지로 교체한다.
2. 이미지가 없으면 새 이미지를 첨부 목록 앞에 넣는다.
3. 나머지 이미지와 문서 첨부의 상대 순서는 유지한다.
4. 제목, 본문, 카테고리, 익명 여부, 참여 링크를 포함한 메타데이터와 마감일은 기존 값을 보존한다.
5. 저장 성공 후 관리자 목록, 사용자 게시판 목록과 게시글 상세 캐시를 무효화한다.
6. 파일 선택 취소는 게시글을 변경하지 않는다.
7. 업로드나 저장 실패는 기존 게시글을 유지하고 관리자에게 오류를 알린다.

대표 이미지 교체는 기존 미디어 업로드와 게시글 수정 API를 사용한다. Alembic, DB 스키마, seed와 수동 DB 작업은 없다.

## Compatibility constraints

- 기존 관리자 공지, 배너, 게시판 설정, 원우회 소개, 건의사항, 상조회, FAQ, 일정 기능을 제거하거나 대체하지 않는다.
- 현재 작업공간의 일정 한국시간 변환 변경을 보존한다.
- 기존 `전체 게시글 관리`의 전체 검색과 상태 필터는 유지한다.
- 관리자 권한 검사는 기존 관리자 화면과 백엔드 API에 계속 의존한다.
- 대표 이미지 변경 버튼은 `club-promo`와 `networking-programs` 게시글에만 표시한다.
- 일반 게시판의 첨부 순서와 수정 동작은 변경하지 않는다.

## Testing and verification

- 그룹별 게시판 필터가 등록된 category를 정확히 분류하고 표준 게시글이 아닌 게시판을 제외하는지 단위 테스트한다.
- 게시판 slug/type별 전용 제어가 공지, 참여 안내, 건의사항, 상조회와 일반 게시판을 정확히 구분하는지 단위 테스트한다.
- 대표 이미지 교체가 첫 이미지만 교체하고 나머지 첨부 순서를 보존하며, 이미지가 없는 경우 앞에 추가하는지 단위 테스트한다.
- 프론트엔드 전체 테스트, 타입 검사, 린트와 웹 export를 실행한다.
- 관리자 화면에서 그룹/게시판 탭, 동아리 대표 이미지 교체, 일반 게시판 공통 기능과 기존 전용 관리자 진입을 확인한다.
