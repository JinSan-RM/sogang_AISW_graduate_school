# 활동 인증 본인 참가자 검색 설계

## 목표

스터디 활동 인증의 참가자 입력 영역에서 작성자가 본인 이름도 검색해 참가자 칩으로 추가할 수 있음을 디자인과 동작에 명확히 반영한다.

## 동작

- 참가자는 이름 검색 결과에서 선택하고 선택된 사람은 `기수 이름` 칩으로 표시한다.
- 로그인한 본인도 활성·재학·회비 납부 또는 면제 조건을 충족하면 다른 회원과 동일하게 검색 결과에 포함된다.
- 본인을 자동 선택하지 않으며 작성자가 직접 검색해 추가한다.
- 같은 사용자는 중복 추가하지 않는다.
- 미납자와 졸업자를 제외하는 기존 자격 조건은 유지한다.

## 화면 문구

참가자 검색 아래 안내를 다음 의미로 표시한다.

`원우회비 미납자, 졸업자는 검색되지 않아요. 지원금은 참가자 목록 기준 지급되니 본인도 검색해서 추가해주세요.`

## 검증

- 사용자 검색 API가 조건을 충족하는 로그인 사용자 본인을 반환하는지 확인한다.
- 참가자 안내 문구에 본인 직접 추가 안내가 포함되는지 확인한다.
- 프론트엔드 전체 테스트와 타입 검사를 실행한다.
