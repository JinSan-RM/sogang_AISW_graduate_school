# Adaptive Post Detail Images Design

## Goal

공지사항과 참여활동 상세 이미지가 원본 방향과 비율에 맞는 높이를 사용하도록 변경한다. 가로 사진과 세로 사진 모두 사용 가능한 가로폭을 채우며, 고정 프레임 때문에 생기는 빈 여백이나 `cover` 처리로 인한 잘림 없이 사진 전체를 표시한다.

이 결정은 `2026-08-10-notice-image-contain-design.md`의 공지 이미지 `230px` 고정 프레임 결정을 대체한다.

## Approved behavior

- 이미지 너비는 해당 상세 화면에서 사용할 수 있는 너비의 `100%`다.
- 이미지가 로드되면 원본 `width / height`를 화면의 `aspectRatio`로 사용한다.
- 가로 사진은 낮고 넓은 영역에, 세로 사진은 원본 비율만큼 길어진 영역에 표시한다.
- 이미지 프레임과 원본 비율이 일치하므로 사진 전체가 보이고, 프레임 내부에 좌우 또는 상하 여백이 생기지 않는다.
- 세로 이미지에 최대 높이를 강제로 적용하지 않는다. 긴 이미지는 상세 화면의 일반 스크롤로 탐색한다.
- 이미지 크기를 아직 알 수 없거나 판독할 수 없을 때만 `16 / 9` 비율을 임시 대체값으로 사용한다.
- 이미지가 바뀌면 새 이미지의 원본 크기로 비율을 다시 계산한다.
- 이미지 열기, 보호 미디어 URL 처리, 갤러리 이동 버튼과 장수 표시는 기존 동작을 유지한다.

## Scope

다음 게시글 상세 이미지에 적용한다.

- `board_type === "notice"`인 공지사항의 이미지 첨부 전체
- `club-promo`와 `networking-programs` 참여 안내의 대표 이미지
- `board_type === "activity_certification"`인 동아리·스터디 등 활동 인증 이미지 갤러리

행사 사진첩, 원우회 활동내역, 상조회 증빙, 일반 커뮤니티 첨부 등 범위 밖 화면의 이미지 정책은 변경하지 않는다.

## Component design

기존 `NaturalAspectMediaImage`를 공통 렌더러로 사용한다. 이 컴포넌트는 로드 이벤트에서 이미지 원본 크기를 읽어 너비 100%와 자연 비율 높이를 만든다.

공지사항은 기존의 `MediaImage resizeMode="contain"`과 `230px` 전용 프레임을 제거하고 `NaturalAspectMediaImage`로 통일한다. 참여 안내와 활동 인증의 대표 이미지 영역도 고정 높이 `visualHero` 대신 자연 비율 컨테이너를 선택한다. 여러 장을 넘길 때는 현재 첨부 ID를 기준으로 이미지 컴포넌트를 새로 구성하여 이전 이미지 비율이 남지 않게 한다.

이미지 주변의 기존 모서리, 화면 여백, 갤러리 화살표와 카운터는 유지하되, 이미지 내부 여백을 만들던 고정 배경 영역만 제거한다.

## Data flow and failure behavior

1. 상세 API 응답에서 이미지 첨부를 선택한다.
2. 미디어 URL을 기존 `MediaImage` 흐름으로 해석하고 이미지를 로드한다.
3. 로드 이벤트의 유효한 원본 크기로 `aspectRatio`를 갱신한다.
4. 유효한 크기가 없으면 임시 `16 / 9` 비율을 유지한다.
5. 갤러리에서 다른 이미지를 선택하면 선택한 이미지 기준으로 같은 과정을 다시 수행한다.

미디어 접근 실패와 첨부 클릭 오류 안내는 기존 처리 방식을 유지한다. 이미지 비율 계산 실패가 상세 화면 전체의 오류로 이어지지 않게 한다.

## Alternatives considered

1. **원본 비율 가변 높이 — 선택.** 여백과 잘림을 동시에 없애며 제공된 가로형·세로형 시안과 일치한다.
2. 방향별 고정 프레임과 `cover`. 화면 높이는 예측 가능하지만 프레임과 다른 원본 비율은 잘린다.
3. 최대 높이와 전체보기 버튼. 긴 화면을 줄일 수 있지만 기본 상세에서 사진 전체가 보인다는 요구를 충족하지 못한다.

## Testing and verification

- 이미지 크기 추출 유틸리티가 유효한 가로·세로 크기를 올바른 비율로 전달하는지 단위 테스트한다.
- 공지 이미지가 고정 `230px`/`contain` 분기를 사용하지 않고 자연 비율 렌더러를 사용하는지 회귀 테스트한다.
- 참여 안내와 활동 인증 대표 이미지가 고정 높이 대신 자연 비율 렌더러를 사용하는지 회귀 테스트한다.
- 갤러리 이미지 변경 시 현재 이미지가 별도 키로 렌더링되는지 확인한다.
- 프론트엔드 테스트, 타입체크, 린트와 웹 빌드를 실행한다.
- 실행 화면에서 가로 이미지와 세로 이미지를 각각 확인해 내부 여백과 잘림이 없는지 캡처로 검증한다.
