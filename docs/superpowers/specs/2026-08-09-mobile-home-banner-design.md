# 모바일 홈 배너 디자인

## 목적

관리자 화면에서 임시 홈 배너로 등록해 사용할 수 있는 모바일 이미지 3종을 제작한다.

## 공통 규격

- 크기: 640×400px
- 화면 비율: 8:5
- 형식: PNG
- 스타일: 깨끗하고 현대적인 디지털 일러스트
- 색상: 서비스 기본색과 어울리는 블루·퍼플 중심
- 안전 영역: 가장자리와 우측 하단 페이지 표시 영역에 핵심 피사체를 배치하지 않는다.
- 제외 요소: 글자, 로고, 워터마크, 인물의 식별 가능한 얼굴

## 배너 구성

1. AI 학습: 노트북과 연결 노드, 은은한 데이터 흐름을 사용한 블루 중심 장면
2. 커뮤니티: 서로 연결되는 추상 인물 실루엣과 대화 요소를 사용한 퍼플 중심 장면
3. 캠퍼스 행사: 현대적인 캠퍼스 공간과 일정·행사를 암시하는 추상 요소를 사용한 블루·퍼플 혼합 장면
