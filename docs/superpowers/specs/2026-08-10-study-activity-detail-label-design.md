# 스터디 활동 인증 상세 라벨 제거 설계

## 목표

`study-activity` 게시판의 활동 인증 상세 화면에서 제목 영역 위에 표시되는 라벨을 제거한다.

## 범위

- 스터디 활동 인증 상세 화면만 라벨을 표시하지 않는다.
- 동아리·네트워킹 활동 인증 상세 화면의 기존 라벨은 유지한다.
- 참여활동 목록 카드와 필터에 표시되는 `활동 인증` 태그는 유지한다.
- 데이터, API, 권한, 작성·수정 흐름은 변경하지 않는다.

## 구현 방식

게시글 상세 화면의 라벨 표시 조건에 `study-activity` 제외 조건을 추가한다. 기존의 게시판별 라벨 계산과 다른 상세 화면 렌더링은 건드리지 않는다.

## 검증

- 스터디 활동 인증 상세에서는 제목 위 라벨이 렌더링되지 않는 회귀 테스트를 추가한다.
- 다른 활동 인증 상세에는 라벨이 유지되는 조건을 함께 확인한다.
- 프론트엔드 전체 테스트와 TypeScript 타입 검사를 실행한다.
