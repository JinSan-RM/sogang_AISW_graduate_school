# 스터디 활동 인증 상세 태그 제거 설계

## 목표

`study-activity` 게시판의 활동 인증 상세 화면에서는 제목 위의 작은 분류 태그를 표시하지 않고, 게시글 제목은 검은 제목 텍스트로 유지한다.

## 범위

- 스터디 활동 인증 상세 화면만 분류 태그를 표시하지 않는다.
- 스터디 활동 인증 상세의 검은 제목은 `post.title`을 사용한다.
- 제목이 비어 있는 레거시 데이터만 기존 분류명 또는 게시판명을 안전한 대체 제목으로 사용한다.
- 동아리·네트워킹 활동 인증 상세 화면의 기존 분류 태그는 유지한다.
- 참여활동 목록 카드와 필터에 표시되는 `활동 인증` 태그는 유지한다.
- 데이터, API, 권한, 작성·수정 흐름은 변경하지 않는다.

## 구현 방식

활동 인증 상세의 헤더 표시 정책을 작은 순수 함수로 분리한다. `study-activity`는 `tagText`를 반환하지 않고 실제 게시글 제목을 `titleText`로 반환한다. 다른 활동 인증 게시판은 지금처럼 분류명을 `tagText`로 반환하고 별도 제목을 추가하지 않는다.

## 검증

- 스터디 활동 인증 상세 정책이 태그 없이 실제 게시글 제목을 반환하는지 확인한다.
- 제목이 비어 있는 레거시 스터디 글은 기존 분류명을 대체 제목으로 사용하는지 확인한다.
- 동아리·네트워킹 활동 인증 상세에는 기존 태그가 유지되는지 확인한다.
- 참여활동 목록과 일반 상세 렌더링 코드는 변경되지 않았는지 확인한다.
- 프론트엔드 전체 테스트, TypeScript 타입 검사, 린트를 실행한다.
