# 홈 인기 게시글 비노출 설계

## 목표

홈 화면의 `🔥 인기 게시글` 섹션만 노출하지 않는다. 게시판 화면의 `인기순` 정렬 기능은 유지한다.

## 설계

- 홈 화면에 `SHOW_HOME_POPULAR_POSTS = false` 플래그를 둔다.
- 인기글 조회, 로딩·오류·빈 상태, 카드 렌더링을 `HomePopularPostsSection` 컴포넌트 블록에 모은다.
- 홈 본문은 플래그가 참일 때만 이 컴포넌트를 마운트한다. 거짓인 동안에는 인기글 API 요청도 발생하지 않는다.
- 요청한 주석 `// 이 부분이 홈 인기게시글 코드입니다.`로 보존 코드의 위치를 표시한다.
- 다른 홈 섹션과 게시판 목록의 정렬 옵션은 변경하지 않는다.

## 검증

- 소스 회귀 테스트로 플래그가 꺼져 있고 인기글 섹션이 조건부 렌더링되는지 확인한다.
- 프론트엔드 타입 검사를 실행한다.
- 웹 홈 화면을 열어 인기 게시글 제목과 카드가 보이지 않는지 확인한다.
